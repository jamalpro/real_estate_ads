# Public Launch Checklist - تقرير عقارات دمشق

Use this checklist for launch work that should not change the dashboard layout or visual design.

## Before sharing publicly

- [ ] Open https://jamalpro.github.io/real_estate_ads/ on desktop.
- [ ] Open it on mobile.
- [ ] Confirm the visible brand says: تقرير عقارات دمشق.
- [ ] Confirm search works with Arabic terms such as: المالكي، المزة، طابو، مستودع.
- [ ] Confirm filters work for area, transaction, category, price, and sort.
- [ ] Confirm raw ad text is still visible on listings.
- [ ] Confirm `robots.txt` is reachable.
- [ ] Confirm `sitemap.xml` is reachable.

## Trust checks

- [ ] No claim that listings are verified unless actually verified.
- [ ] No claim that the project is a brokerage or office.
- [ ] No claim that prices are guaranteed current.
- [ ] No conversion of SYP to USD without source.
- [ ] Any unclear price, title, ownership, or area remains marked for review in the data.

## Sharing channels

- [ ] WhatsApp family/friends test group.
- [ ] One small real-estate discussion group.
- [ ] One Facebook post or group comment.
- [ ] Ask early users for missing areas, duplicate listings, and confusing filters.

## Suggested Arabic launch copy

عملت صفحة بسيطة اسمها **تقرير عقارات دمشق** تجمع وتنظم إعلانات العقارات بدمشق، مع بحث وفلترة حسب المنطقة والسعر والمساحة ونوع العقار. الهدف مو مكتب عقاري ولا عمولة، بس مرجع مرتب بدل فوضى الواتساب. جرّبوها وإذا شفتوا خطأ أو إعلان مكرر خبروني:

https://jamalpro.github.io/real_estate_ads/

## No-layout-change rule

For this phase, avoid:

- changing CSS layout
- adding hero sections
- adding modals
- adding new visible buttons
- changing card structure
- rebuilding from a mismatched template unless the data/template state is known clean
